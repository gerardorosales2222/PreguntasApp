## ¿Qué es un StatefulWidget?
Es un Widget. Posee un estado interno y puede cambiar de estado durante la ejecución. Se reconstruye la interface de usuario cada vez que se ejecuta una nueva acción. 



## ¿Qué es un Widget? y ¿que es un const?
Es una unidad básica de contrucción de interface de usuario de Flutter. Controla su comportamiento mediante Propiedades. El nombre del Widget va en Mayúsculas y la propiedad en minúsculas. 

Const difine a un widget como constante y significa que el Estado del mismo no va a cambiar y no se va a recargar constantemente ayudando a la optimización de recursos. 


## ¿Qué es un build?
